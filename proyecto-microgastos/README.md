Descripcion:
Aplicación web desarrollada en React para ayudar a las personas a registrar y controlar sus gastos hormiga diarios, como cafés, snacks, transporte y pequeños antojos que afectan el ahorro mensual.

Requisitos previos:
Este proyecto corresponde al Primer Avance del Proyecto Integrador - Front 2, enfocado en la creación de una arquitectura escalable y un flujo de trabajo colaborativo usando Git y GitHub.

Tecnologias usadas:
React-Vite-JavaScript-HTML-CSS-Git-GitHub
